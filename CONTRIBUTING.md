# Поддержка портфолио

Описание автора и избранных проектов редактируется вручную. Каталог между маркерами `PROJECTS` и статистика между маркерами `STATS` генерируются автоматически.

GitHub Actions проверяет генератор при push и pull request. В основной ветке обновляет каталог и SVG при push, вручную через **Actions → Portfolio → Run workflow**, а также по понедельникам в 09:17 по московскому времени (06:17 UTC; возможна задержка расписания GitHub).

Используется встроенный `GITHUB_TOKEN`, отдельный персональный токен и Vercel не нужны. Только задача обновления имеет `contents: write`; проверки pull request работают с чтением. При ошибке API опубликованные данные остаются прежними.

Источник — публичный список репозиториев DIBERLOG. Закрытые репозитории не публикуются. Список `EXCLUDED` в генераторе определяет исключения автора. Форки отмечены в каталоге, но не участвуют в статистике. Звёзды и форки суммируются по проектам портфолио. Круговая диаграмма «Топ языков» показывает доли по суммарному объёму кода в байтах из GitHub Linguist (`/languages`); малые доли объединяются в «Другие». Приватная активность и contributions не подсчитываются.

Новый публичный репозиторий попадёт в каталог автоматически; заполните его Description. Для выделения кейса добавьте описание в README. Инструкции запуска и лицензии остаются в каждом проекте.

## Локальная проверка

Нужен Python 3.12 или новее, сторонние библиотеки не требуются.

```sh
python -m unittest discover -s scripts -p 'test_*.py'
python scripts/update_portfolio.py
```

Для сохранённого ответа публичного GitHub API:

```sh
python scripts/update_portfolio.py --snapshot repos.json
```

Ошибки и предложения отправляйте через Issues. Изменения текста — через pull request. Не добавляйте API-ключи и личные данные.
